Threshold

Garmin MCP server: ask Claude or ChatGPT about your training

Threshold is an open-source Garmin MCP server. It connects your Garmin Connect data to Claude, ChatGPT, Cursor and any AI assistant through the Model Context Protocol, using Garmin's official Personal API. It computes readiness, HRV baselines, training load and FIT-file analysis in code, and runs free on your own Cloudflare account.

Ask: "Am I recovered enough for intervals today?" · "Is my HRV trending down?" · "Am I ramping up too fast?" · "Break down this morning's run."

What it does

Daily readiness

HRV, resting heart rate, sleep, Body Battery, training form and load ramp against your own 60-day baselines, with a clear green, amber or red call.

Training load

Fitness (CTL), fatigue (ATL), form (TSB), acute:chronic workload ratio, monotony and strain, by week and by sport.

FIT file analysis

Splits, HR zones, fastest 1k to marathon, power curve, aerobic decoupling and cardiac drift, NP, IF and TSS.

Hidden VO2 max

Decodes VO2 max and performance condition that Garmin writes into FIT files but leaves out of the API.

Full history + SQL

A private archive of every day and activity, with a read-only SQL tool for any question.

Works everywhere

Claude web, desktop, iOS and Android, ChatGPT, Claude Code, Cursor, VS Code, Codex, Gemini CLI, Windsurf.

Set up in five minutes

  • Create a Garmin Personal API key in Garmin Connect.
  • Click Deploy to Cloudflare and paste your key and a random access key.
  • Add your server's /mcp URL as a custom connector in Claude or ChatGPT.

Frequently asked questions

What is a Garmin MCP server?

An MCP server exposes data and tools to AI assistants through the Model Context Protocol. A Garmin MCP server lets Claude, ChatGPT or another assistant read your Garmin Connect data and answer questions about it. Threshold also analyzes the data in code: readiness, training load, HRV baselines and best efforts.

How do I connect my Garmin to Claude?

Deploy Threshold to Cloudflare with one click, then in Claude open Settings → Connectors → Add custom connector, paste your server's /mcp URL and sign in with your access key. It works on claude.ai, Claude Desktop and the Claude mobile apps.

How do I connect my Garmin to ChatGPT?

Turn on Developer mode in ChatGPT, create a connector with your Threshold /mcp URL, choose OAuth, and enter your access key.

Does it need my Garmin password?

No. Threshold uses a revocable Garmin Personal API key that you create in Garmin Connect. It never asks for your password.

Is Threshold free?

Yes. It is MIT-licensed and runs on Cloudflare's Workers Free plan.

Can it change anything on my Garmin account?

No. The Garmin Personal API is read-only, and so is Threshold.
