Cloudflare dashboard → Workers & Pages → threshold → Settings → Variables and secrets → Add. Choose type Secret, enter GARMIN_API_KEY or ACCESS_KEY and the value, then Deploy. If a key is missing, your server’s page says which one and suggests a strong access key.

Under the hood

      
HOW IT

      
WORKS.

    

    

      

    

    

      
01
Archive first
Tools read a D1 archive and fetch only missing or recent days. Recent days are re-checked, because watches sync late.

      
02
Background sync
Every 10 minutes a cron job refreshes recent days and walks back through your history, inside the Workers limits.

      
03
Fast FIT decoder
Reads a one-hour activity in about a millisecond, 20× faster than Garmin’s JavaScript SDK.

      
04
Hidden metrics
VO2 max = field 7 × 3.5 / 65536 from message 140. Anything less certain is labelled experimental.

Privacy and security

      
YOUR DATA.

      
YOUR ACCOUNT.

    

    

      
◉
Single user
Built for one person on their own Cloudflare account. No hosted service; your data never passes through this project.

      
⌁
Key stays put
The Garmin key never leaves the Worker. It is exchanged for a 24-hour token cached in your KV.

      
◎
Read-only
The Personal API cannot change your Garmin account, and the SQL tool refuses anything but SELECT.

      
⊘
Only you connect
The consent page asks for your access key, shows where tokens go, and warns about local apps.

      
⌖
Less exposure
GPS coordinates, place names and personal identifiers are removed from responses unless you ask.

    

  







  

    

      
FAQ

      
QUESTIONS.

      
More in the README.

    

    

      
What is a Garmin MCP server?
An MCP server exposes data and tools to AI assistants through the Model Context Protocol. A Garmin MCP server lets Claude, ChatGPT or another assistant read your Garmin Connect data and answer questions about it. Threshold also analyzes the data in code: readiness, training load, HRV baselines and best efforts.

      
How do I connect my Garmin to Claude?
Deploy Threshold to Cloudflare with one click, then in Claude open Settings → Connectors → Add custom connector, paste your server’s /mcp URL and sign in with your access key. It works on claude.ai, Claude Desktop and the Claude mobile apps.

      
How do I connect my Garmin to ChatGPT?
Turn on Developer mode in ChatGPT, create a connector with your Threshold /mcp URL, choose OAuth, and enter your access key.

      
Does it need my Garmin password?
No. Threshold uses a revocable Garmin Personal API key that you create in Garmin Connect. It never asks for your password.

      
Is Threshold free?
Yes. It is MIT-licensed and runs on Cloudflare’s Workers Free plan.

      
Can it change anything on my Garmin account?
No. The Garmin Personal API is read-only, and so is Threshold.
